# PBL - KELOMPOK 5

Proyek ini berfokus pada pengembangan aplikasi **Polinema Care+**, sebuah "ruang aman" digital yang dirancang khusus untuk memfasilitasi pelaporan dan konseling mahasiswa.

## Deskripsi

Polinema Care+ dibangun untuk memberikan solusi responsif terhadap kebutuhan layanan pendampingan mahasiswa. Aplikasi ini menyediakan antarmuka pengguna yang ramah dan sistem navigasi yang efisien untuk memastikan mahasiswa dapat mengakses layanan pelaporan dan konseling kampus dengan mudah dan aman.
